General Game Plan

Our objectives include fine-tuning YOLO v8 for outdoor environments, establishing performance metrics (mAP, IoU, precision, recall), and integrating a vision system with ROS2 and LLMs to generate real-time warnings for potential hazards.

Lab Notebook

Week of 1/17/2025-1/24/2025

Initiated dataset download and set up training, testing, and validation sets for YOLO v8. Explored annotation workflows using Roboflow and analyzed early training metrics.

Read More

Detailed progress includes training metrics visualization, debugging of annotation issues, and the establishment of baseline performance for object detection and segmentation tasks.

Week of 1/25–1/31:
Used YOLOv8 segmentation to label roads (danger zones) and sidewalks (safe zones). Extracted video frames for instance segmentation. Learned the distinction between detection vs. segmentation data formats and fixed label mismatches.

Week of 2/2–2/9:
Trained YOLOv8 on Phoenix street footage. Implemented a “walkable zone” model with green overlays for safe navigation. Visualized results via video and segmentation overlays.

Week of 2/9–2/15:
Developed a Proximity Detection algorithm using bounding boxes and real-time video overlays to identify collision risks. Refined walkable zones and tested different video input environments.

Week of 2/16–3/1:
Evaluated vision-language models (VILA, BLIP, VILT, LLaVA). Found VILA-2.7b to be most context-aware. Integrated object detection with semantic terrain analysis for robust scene understanding.

Week of 3/1–3/8:
Deployed the walkable model on the Yakuza robot dog. Achieved 100x faster inference using GPU optimization. Fine-tuned performance under low-light conditions and compared small-scale VLMs for urban terrain interpretation.

Week of 3/8–3/22:
Tested 8 Vision Language Models through Ollama for terrain, safety, and hazard comprehension. Scored models by descriptiveness and speed. Started framework for integrating VLM and YOLOv8 outputs for smart, real-time alerts.

Results

The implementation successfully identifies safe zones (e.g., sidewalks) and obstacles (e.g., vehicles, poles) using instance segmentation. Videos and performance metrics demonstrate improved inference times (up to 100× faster on GPU) and robust detection under varying conditions.
